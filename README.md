# 🍽️ Restaurant Website (Figma to Code)

A modern, and interactive restaurant landing page faithfully converted from a Figma design using clean **HTML5**, **CSS3**, and **Vanilla JavaScript**.

---

## 🔗 Live Demo & Links

- **GitHub Repository:** [https://github.com/tarunkaushik00/resturant-website](https://github.com/tarunkaushik00/resturant-website)
- **Live Demo:** `https://tarunkaushik00.github.io/resturant-website/` *(GitHub Pages enable karne ke baad)*

---

## ✨ Features

- **Pixel-Perfect UI:** Accurate recreation of typography, color schemes, card layouts, and spacing from the Figma design.
- **Interactive Food Menu:** Filterable dishes, price cards, and detailed item views.
- **Table Booking / Contact Form:** Front-end interactive form with input validation built using pure JavaScript.
- **Fully Responsive Design:** Seamless experience across smartphones, tablets, laptops, and ultra-wide screens.
- **Smooth Navigation:** Sticky navigation bar, mobile hamburger menu, and smooth scrolling between sections.
- **Engaging Visuals:** Hero banner, chef highlights, daily specials, and customer review cards.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<section>`, `<footer>`) for SEO and accessibility.
- **CSS3:** Flexbox, CSS Grid, media queries, CSS variables, and hover animations.
- **JavaScript (ES6+):** DOM manipulation, menu toggles, and event-driven interactions.
